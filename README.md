## 🕯️ Overview

**The Legacy Ledger** is a local-first, privacy-focused oral history companion designed to capture, structure, and preserve life stories and family traditions. 

In a digital age where personal reflections and family records often get lost in ephemeral chat apps or swallowed by third-party clouds, *The Legacy Ledger* brings back the warmth of an heirloom journal—giving your stories a structured, permanent home without compromising your data privacy.

---

## ✨ Key Features

- **🎙️ Spoken & Written Memory Capture:** Seamlessly record unstructured audio notes or type out personal reflections and family anecdotes.
- **🏷️ Smart Structuring & Categorization:** Automatically tag and organize memories into intuitive life eras (*Childhood*, *Family Traditions*, *Milestones*, *Wisdom*).
- **⌛ Visual Family Timeline:** Browse recorded stories through a clean, chronological timeline with fast keyword searching and topic filtering.
- **📖 Heirloom Reader View:** Experience memories in a cozy, parchment-styled reader layout optimized for immersion.
- **🔒 Private & Local-First:** Your stories stay on your device. Zero cloud surveillance, zero third-party tracking.
- **📄 Export to Keepsake PDF:** Instantly format your accumulated ledger entries into a clean, printable family archive.

## 🛠️ Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS (Archival / Warm Aesthetic)
- **Icons:** Lucide React
- **State & Persistence:** React Context / Local Storage

## 🚀 Getting Started Locally

To run **The Legacy Ledger** on your local machine, follow these simple steps:

### 1. Clone the repository
```bash
git clone [https://github.com/sakshi-db/the-legacy-ledger.git](https://github.com/sakshi-db/the-legacy-ledger.git)
cd the-legacy-ledger
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open http://localhost:5173 in your browser to view the app!

## 🎨 Design Philosophy

- Warmth over Utility: Built using muted amber, deep slate, and warm parchment tones to feel like a timeless physical journal rather than a cold software dashboard.
- Simplicity First: Thoughtfully crafted so family members of any age can easily share and navigate stories without technical friction.
